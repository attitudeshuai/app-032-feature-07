# 花灯骨架放样与蒙面裁片 · Lantern Frame Lofting

纯前端工具：选灯型 → 填直径/高度/收口 → 出「每根竹篾截多长、弯什么角度」的骨架件表、带缝份的蒙面裁片、以及可 100% 打印的 1:1 放样图与备料单。无后端、无网络请求，断网可用。

## 技术栈

- Vue 3（`<script setup>` 单文件组件）+ TypeScript + Vite 6
- 状态：Vue 自带 `ref / reactive / computed / watch`（无 Pinia / Vuex）
- 额外依赖仅 `vue-router` 4（规格书要求的 6 个路由）
- 手写 CSS；无 UI 组件库、无图表库、无游戏引擎/物理库
- 字体、灯型数据包（`src/data/lantern-types.json`）全部本地打包，无外网 CDN

## 打印比例校验（图纸页）

打印完把量到的 100mm 校验尺长度填回「打印比例校验」，页面按标称长度算出这次实际的比例并判定容差（±1mm）：

- **未超差**：比例记在这盏灯上（本机存档），1:1 放样图每一页角注、三份导出单子（构件清单 / 裁片清单 / 备料单）角注、构件表与裁片页同用这一份；改纸张或搭接量会整份重排分页并一起刷新。
- **超差**：这套图纸标为不可用，给出改法（关掉「适应页面」/ 换幅面更大的纸 / 分幅打印），并二选一认下代价：
  - **按实测比例换算下料**：图纸照旧能用，构件表 / 裁片页 / 导出单子给出「纸上读数 → 实际下料」对照（实际下料 = 纸上读数 ÷ 实测比例）；代价是每一次下刀都要按新比例重新读数。
  - **要求重打到原大**：纸上量多少就是多少；代价是图纸与随附单子重出，已发到作坊的一套作废。
- 导出 / 打印即登记比例签名；改比例或改取舍后，仍按老比例出具的那一处会被点名作废（含已照裁的裁片）。
- 精度：实测长度 mm 留 1 位小数；比例 % 留 2 位小数；换算 cm 留 1 位小数。旧灯样没有校验记录时按「未校验」处理，不当成原大。
